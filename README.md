# NexStream Player

**NexStream Player** is a premium IPTV/OTT media player for Android phones, tablets and Android TV, with a backend API and a web portal for device activation and playlist management.

> NexStream is a player only. It does not provide, sell or host any audiovisual content; users load their own legally obtained playlists.

## Overview

- **Android app**: native Kotlin + Jetpack Compose, one APK for mobile and Android TV.
- **Device activation**: each install generates a **Device ID** (MAC-style) and an 8-character **Device Key**.
- **Backend API**: Node.js + TypeScript + Express.
- **Web portal**: dark landing page for device login and playlist management.
